# Doodle Jump Klonu

Oyun geliştirmeyi öğrenmek için eğitim sürecinde yaptığım, Unity ile geliştirilmiş bir Doodle Jump klonu. Karakter platformlardan platformlara zıplayarak yukarı çıkar, aşağı düşerse oyun biter.

## İçerik

- Oyuncu hareketi (Player Controller)
- Platform üretimi ve kontrolü (Platform Controller, Level Manager)
- Kamera takibi (Camera Controller)
- Düşme algılama ve oyun sonu (Kill Collider, Game Manager)

## Kullanılan Teknolojiler

- Unity
- C#

# Doodle Jump Clone

A Doodle Jump clone built with Unity, made as part of my learning process while studying game development. The character jumps from platform to platform to climb higher, and the game ends if the player falls.

## Contents

- Player movement (Player Controller)
- Platform generation and control (Platform Controller, Level Manager)
- Camera follow (Camera Controller)
- Fall detection and game over (Kill Collider, Game Manager)

## Built With

- Unity
- C#
